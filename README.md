# 🥭 তাজা বাজার - রুপালি আম অনলাইন অর্ডার

**তাজা বাজার** একটি মোবাইল-ফ্রেন্ডলি ওয়েবসাইট যা দিয়ে আপনি রুপালি আম অনলাইনে বিক্রি করতে পারবেন। ক্রেতারা অর্ডার করলে আপনি সাথে সাথে ইমেইল ও এসএমএস নোটিফিকেশন পাবেন।

## 🚀 কিভাবে চালাবেন

### ১. প্রজেক্ট শুরু

```bash
cd taza-bazar
npm install
```

### ২. এনভায়রনমেন্ট সেটআপ

`.env` ফাইল তৈরি করুন (`.env.example` কপি করে):

```env
PORT=3000
OWNER_PHONE=01629518850
OWNER_EMAIL=hafezyeasin93@gmail.com
```

**ইমেইল নোটিফিকেশন চালু করতে (Gmail):**
```env
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_SECURE=false
EMAIL_USER=your-email@gmail.com
EMAIL_PASS=your-app-password   # Gmail App Password ব্যবহার করুন
```

**এসএমএস নোটিফিকেশন চালু করতে (Twilio):**
```env
TWILIO_ACCOUNT_SID=your-account-sid
TWILIO_AUTH_TOKEN=your-auth-token
TWILIO_PHONE_NUMBER=+1234567890
```

> **বিঃদ্রঃ**: ইমেইল/এসএমএস কনফিগার না করলেও ওয়েবসাইট কাজ করবে। শুধু নোটিফিকেশন যাবে না।

### ৩. সার্ভার চালু

```bash
npm start
```

সার্ভার চালু হবে: **http://localhost:3000**

## 🌐 ডিপ্লয়মেন্ট

### Render.com (ফ্রি)
1. GitHub-এ প্রজেক্ট আপলোড করুন
2. Render.com-এ নতুন Web Service তৈরি করুন
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Environment Variables সেট করুন

### Railway.app (ফ্রি)
1. GitHub থেকে ইম্পোর্ট করুন
2. Start Command: `npm start`
3. Variables যোগ করুন

### লোকাল মেশিনে পার্মানেন্টলি (PM2)
```bash
npm install -g pm2
pm2 start server.js --name taza-bazar
pm2 save
pm2 startup
```
